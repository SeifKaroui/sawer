# Sawer icons

Sawer renders icons directly as native line, arc, circle, and triangle geometry;
it does not load SVGs at runtime.

Standard interface icons follow Lucide's 24 by 24 optical grid: centered
1.75-unit strokes, round caps and joins, consistent padding, and comparable
visual density. Board-pattern previews remain Sawer-specific because they
represent application data rather than general interface actions.

The current native geometry is converted from Lucide 1.26.0. Sawer uses
`file-plus`, `folder`, `house`, `save`, `mouse-pointer-2`, `hand`,
`pencil`, `slash`, `minus`, `plus`, `rectangle-horizontal`, `ellipse`, `ban`,
`undo-2`, `redo-2`, `copy`, `copy-plus`, `scissors`, `clipboard-paste`, `trash-2`,
`zoom-out`, `zoom-in`, `sun`, `grid-2x2`, `arrow-left`, `sliders-horizontal`,
`x`, `info`, `check`, `chevron-left`, and `chevron-right`.
The custom-color palette and crescent moon symbols follow the same optical grid.
Line-width samples and board-pattern previews intentionally remain data-driven
Sawer geometry.
